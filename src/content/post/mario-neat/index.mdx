Technical Explanation (45 seconds)

Onto the technical explanation, the program is coded in LUA using the FCEUX64 emulator. The connections and hidden nodes are not being shown since there are performance issues if the emulator shows too many lines at once.
The program begins with 300 neural networks in generation number 1, which I’ll call genomes. It starts out with no information on how to play the game, but it’ll eventually learn how to move forward.
This will increase its fitness score which is used to determine if that genome is worthy enough to move on to the next generation, similar to how evolution works. To promote diversity of neural networks, all genomes that are similar to each other are grouped together to optimize their structures.
